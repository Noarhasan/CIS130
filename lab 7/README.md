Lab 7 - Responsive Web Design

1. Layout Problems

I tested my website on different screen sizes. I noticed two problems:

* The content and sidebar did not fit well on small screens.
* The navigation menu needed to be easier to use on mobile devices.

2. Breakpoint Choice

I used a 768px breakpoint. Below this width, the main content appears in one column. At 768px and above, the main content and sidebar appear next to each other.

3. Navigation Changes

I changed the navigation menu to use Flexbox. On small screens, the links appear vertically. On larger screens, they appear horizontally. I also kept the hover, focus, and submenu styles.

4. Container Query

I added a card panel with two cards about my life in Yemen and Egypt. I used a container query with a minimum width of 500px. When the card panel is wide enough, the cards appear next to each other. On smaller widths, they appear in one column.

5. Testing

I tested my website using Google Chrome Device Toolbar at these widths:

* 390px (Mobile)
* 768px (Tablet)
* 1200px (Desktop)

The website works at all three screen sizes.

I improved my existing website by adding responsive design features. The website is now easier to use on mobile devices and larger screens.
